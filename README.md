# down

haohao-ui 各项目的公开下载与 Claude Code 插件市场。

- 二进制发布在 [Releases](https://github.com/haohao-ui/down/releases)，tag 以项目名为前缀：`<项目>-vX.Y.Z` 为固定版本，`<项目>-latest` 始终指向最新版。
- 本仓库同时是 Claude Code 插件市场：

```
/plugin marketplace add haohao-ui/down
```

## 项目

| 项目 | 说明 | 安装 |
|---|---|---|
| [viddl-mcp](viddl-mcp/) | 多平台视频/图集下载 MCP（抖音 / TikTok / 小红书 / YouTube / 快手） | `/plugin install viddl@down` |
